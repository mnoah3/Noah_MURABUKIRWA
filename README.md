This Java project includes three advanced OOP-based systems:

Vehicle Tax Management System – Registers vehicles, calculates taxes based on type and age, and generates reports.

RRA Tax Enforcement System – Simulates Rwanda Revenue Authority processes for PAYE, VAT, and Withholding Tax declarations, compliance, and penalties.

Internship Management System – Manages student internships across multiple universities with supervisor assignment, validation, and reporting.

Each module uses core OOP principles like abstraction, inheritance, encapsulation, polymorphism, and interfaces, with Scanner for user input and ArrayList for data storage.
